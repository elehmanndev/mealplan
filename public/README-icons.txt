PWA icons go here.

Required files (drop them into /public alongside this README):

  icon-192.png            — 192×192 PNG, opaque background
  icon-512.png            — 512×512 PNG, opaque background
  icon-512-maskable.png   — 512×512 PNG with safe-zone padding (maskable)
  apple-touch-icon.png    — 180×180 PNG (iOS home-screen icon)

Recommended generator:
  https://realfavicongenerator.net/
  Use the 🍽️ emoji on a #0f0f0f (dark) background.
  Set the maskable safe zone (shrink the emoji ~80%) so it survives
  Android's circular/squircle masks.

Until real PNGs are dropped here, the manifest will reference 404'd icons
and the install banner won't show. The app itself still runs fine.
